# 🦖 Arduino Dino Game with 16x2 LCD | Wokwi Simulator
A fun implementation of the classic Chrome Dino game using an Arduino Uno and a 16x2 LCD display. Built and tested in the Wokwi online simulator, this project demonstrates game development concepts, LCD graphics, and embedded programming with Arduino. 0
---
## 🎮 Features
- 🦖 Dinosaur character animation
- 🌵 Moving obstacles
- ⬆️ Push button to make the dinosaur jump
- 📈 Score tracking
- 💀 Game Over screen
- 🔄 Restart option
- 💻 Runs entirely in the Wokwi simulator
---
## 🛠️ Components Used
- Arduino Uno
- 16×2 LCD Display
- Push Button
- 10kΩ Resistor (for LCD contrast, if required)
- Breadboard
- Jumper Wires
- Wokwi Simulator
---
## 🚀 How to Play
1. Start the simulation in Wokwi.
2. Press the button to make the dinosaur jump.
3. Avoid hitting the obstacles.
4. Your score increases as you survive longer.
5. If the dinosaur collides with an obstacle, the game ends.
6. Restart the game and try to beat your high score.
